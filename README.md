# Focus Canvas

סקיל של האקדמיה של פוקוס שהופך את קלוד קוד, וגם את קודקס, למעצב שעובד בשכבות. כותבים לו בעברית איזו תמונה
רוצים, מאשרים תוכנית קצרה עם המחיר, והוא בונה את התמונה: בינה מלאכותית מייצרת את מה שהיא טובה בו, קוד כותב את מה
שחייב להיות מדויק, ודף עריכה מקומי נפתח כדי להזיז, להגדיל ולסובב כל שכבה ולשמור.

המדריך המלא בעברית, עם הפרומפטים המוכנים:

https://focusai.co.il/guides/focus-canvas/

## מה אפשר לעשות איתו

- פוסט, סטורי, פוסטר או תמונה לקישור, מתמונות ולוגו שלכם או מאפס.
- חותמת, סרט או דמות על פוסטר קיים, בלי לייצר את הפוסטר מחדש.
- טקסט בעברית בפונט אמיתי, מימין לשמאל, בדיוק כמו שכתבתם. אף פעם לא פיקסלים ממודל תמונה.
- קיר תמונות מהצילומים שלכם, משבצת אחרי משבצת.
- סדרת איורים בסגנון אחד, עם אותה דמות ואותו חדר, לקרוסלה או לסרטון.
- אותה תמונה בכל גודל: פוסט, סטורי, ריבוע, תמונה לקישור.

## מה צריך

- קלוד קוד או קודקס על מחשב עם חלונות או מק, וגרסה 20 ומעלה של

  `Node.js`

- בשביל לייצר תמונות חדשות: חיבור לשירות תמונות דרך המחשב שלכם, בלי שום מפתח. הסקיל בודק לבד מה מחובר, ואם אין
  כלום הוא מציע שלוש אפשרויות ומחכה להחלטה שלכם. העריכה, דף העריכה, הבדיקות והייצוא עובדים גם בלי חיבור.
- בפעם הראשונה הסקיל מתקין לבד שתי חבילות ודפדפן, אחרי שאתם מאשרים.

## התקנה

מדביקים בקלוד קוד את שתי השורות, אחת אחרי השנייה:

```
/plugin marketplace add FOCUS-OS-DEV/focus-canvas
/plugin install focus-canvas@focus-ai-academy
```

או בדרך הכי פשוטה: מדביקים בקלוד קוד או בקודקס את הפרומפט הזה, והכלי מתקין לבד:

```
תתקין לי את הסקיל Focus Canvas של האקדמיה של פוקוס.
המאגר: https://github.com/FOCUS-OS-DEV/focus-canvas
אם אתה קלוד קוד: תריץ את שתי הפקודות האלה, אחת אחרי השנייה:
claude plugin marketplace add FOCUS-OS-DEV/focus-canvas
claude plugin install focus-canvas@focus-ai-academy
אם אתה קודקס: תשכפל את המאגר, תריץ בתוכו את שתי הפקודות האלה, אחת אחרי השנייה:
npm install
npx playwright install chromium
ואז תעתיק את התיקייה skills/image לתוך התיקייה הזאת:
~/.agents/skills/focus-canvas
אם משהו לא עובד, תגיד לי בדיוק מה להקליד כאן בצ'אט כדי להתקין.
בסוף תגיד לי לסגור ולפתוח מחדש את הכלי.
```

בקודקס אפשר גם ידנית: משכפלים את המאגר, מריצים בתוכו את שתי הפקודות האלה, אחת אחרי השנייה, ומעתיקים את התיקייה
`skills/image` לתוך `~/.agents/skills/focus-canvas`:

```
npm install
npx playwright install chromium
```

אחרי ההתקנה סוגרים ופותחים מחדש את הכלי, ואז כותבים:

```
תעשה לי פוסט לאינסטגרם
```

בפעם הראשונה הסקיל בודק את המחשב, מראה תמונת בדיקה, ואומר דרך איזה חיבור ייווצרו התמונות.

כשיוצאת גרסה חדשה, מעדכנים בשורה אחת:

```
/plugin update focus-canvas@focus-ai-academy
```

## החיבור לשירות התמונות

הסקיל לא מחזיק מפתח ולא מבקש מפתח, אף פעם. התמונות נוצרות דרך חיבור שאתם עושים בעצמכם בקלוד קוד או בקודקס,
וההתחברות היא בדפדפן. הסקיל בודק מה מחובר אצלכם לפני כל ייצור. אם כבר יש חיבור, הוא אומר איזה ועובד איתו. אם אין,
הוא מציג שלוש אפשרויות, עם שורת ההתקנה, המחיר ואופן התשלום של כל אחת, ולא מתקין כלום עד שאתם מחליטים ומריצים
את השורה בעצמכם, או אומרים לו להריץ אותה.

1. המומלץ. תשלום מראש, בלי מנוי: טוענים כמה דולרים וכל תמונה יורדת מהיתרה. מכסה כל שלב של הסקיל.

   `fal`

2. תשלום לפי שימוש, בלי מנוי: יתרה מראש או חיוב חודשי על מה שנוצל.

   `Replicate`

3. מנוי חודשי עם כמות קרדיטים קבועה. דרך החיבור כל תמונה עולה קרדיטים, גם במסלולים שמציעים "ללא הגבלה" באתר.

   `Higgsfield`

המחירים המדויקים כתובים בסקיל עם התאריך שבו נקראו מדפי הספקים, והם יכולים להשתנות. ההמלצה שלנו: לטעון כמה דולרים
בכל פעם ולא יותר, כדי שההוצאה תישאר בשליטה. לפני כל תמונה בתשלום הסקיל אומר כמה היא עולה ומחכה לאישור, ואחרי
כל שלב הוא מדווח כמה יצא.

## איך זה עובד

1. אומרים מה רוצים. הסקיל שואל שאלה או שתיים, ולכל שאלה יש ברירת מחדל.
2. מקבלים תוכנית: מה התמונה אומרת, כל מילה שתופיע בה, מה נוצר בבינה מלאכותית ומה קוד כותב, מה נשאר כמו שהוא,
   הגדלים, השירות והמחיר. רק אחרי "כן" משהו עולה כסף.
3. הסקיל מייצר, חותך ומרכיב, ובודק את התמונה לפני שאתם רואים אותה: אזור בטוח, גודל טקסט, ניגודיות, עברית.
4. דף העריכה נפתח: לוחצים על חלק, גוררים, מגדילים, מסובבים, משנים מילים, ממלאים את קיר התמונות, ולוחצים שמירה.
5. הסקיל ממשיך מהקובץ ששמרתם, ומוציא את הגרסה הסופית בכל הגדלים.

## טוב לדעת

- התמונות, הלוגו והפוסטרים שלכם לא משתנים ולא נוצרים מחדש. מה שחדש עולה עליהם.
- כל תמונה נשמרת בתיקייה מסודרת משלה, עם קובץ אחד שהוא התמונה (`layers.json`) וכל גרסה קודמת.
- כל שלב בתשלום מצוטט לפני ומדווח אחרי, לפי מחירי הספק, ונרשם בקובץ העלויות של התמונה.
- שבע משפחות פונטים בעברית מגיעות עם הסקיל, ברישיון פתוח.
